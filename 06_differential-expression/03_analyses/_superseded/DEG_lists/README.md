# _superseded/DEG_lists

Written by the superseded DESeq2 scripts. `FG_*_countmatrix.csv`, `LC_countmatrix.csv`,
`TC_countmatrix.csv`: count subsets for each fit. `DEG_provenance_check.csv`: the old check
that re-derived the TC tables. `Foot/` and `Gill/`: per-contrast count and sample tables.
The 16 sample lists in `../../DEG_lists/contrast_samples.csv` reproduce the ones here exactly.

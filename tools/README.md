# tools

Shared R helpers sourced by the analysis folders (base R, plus rmarkdown and ggplot2 where noted),
and the script that sets up the software environment.

| File | Used by | What it does |
|---|---|---|
| `run_steps.R` | every `00_run_*.Rmd` and the repository-level `00_run_pipeline.Rmd` | renders each numbered script in its own R process with an HTML report and a log, keeps `run_log.csv` (with each step's log file), and stops on the first failure, quoting the failed step's error from its log (`render_step()`, `list_steps()`, `run_steps()`, `log_tail()`, `finish_run()`); `check_stack()`, called by `00_run_pipeline.Rmd` before its first stage, stops when R's minor version, Bioconductor's or (for a run with `07` or `08`) the GO release in `GO.db` differs from `renv.lock`, or when a package of `PIPELINE_PACKAGES` (those the scripts load) is not on R's library path, printing `.libPaths()`; it reports other `renv.lock` packages that are missing, and packages at another version |
| `plot_style.R` | every script that draws a figure (02, 04, 06, 07, 08, 09) | the one set of colours and the shared ggplot theme: treatments (control grey, OA green, OW orange, DO purple), thread condition (adds baseline blue and lab reference light grey), direction (red up, blue down), tissue and foot region. Validated for colour-vision deficiency. Also `short_name()`, which shortens a UniProt protein name for a figure label: it drops the alternative names in parentheses and the `[Cleaved into: ...]` / `[Includes: ...]` sections, keeps brackets that belong to the recommended name (`Amine oxidase [flavin-containing] A`), and cuts at a word boundary |
| `gene_ids.R` | `06_iso-seq-transcriptome` (03, 04), `04_sequence-alignment` (04, 05, 07 and `_derive_mt_like_loci.R`), `05_differential-expression` (01, 06, 13), `07_enrichment` (01), `09_gene-mechanics-correlation` (01, 03, 04, 05), `mt_encoded.R` | `gene_key()`: the join key of a count-matrix gene name, the LOC identifier when the name holds one (`gene-LOC1\|LOC1`, `gene-LOC1`, `STRG.10\|LOC1`), otherwise the gene ID without `gene-` (`ND2`, `Trnaa-agc-10`, `STRG.12`). Unique over the 47,806 matrix rows; it replaces four slightly different local versions, one of which collapsed the tRNA genes onto their shared name and one of which left `gene-` on the 476 names without `\|` |
| `mt_encoded.R` | `04_sequence-alignment` (04, 05, on the annotation's genes), `05_differential-expression` (01) | the mitochondrial loci of a gene list (the count matrix, or the annotation's genes): the 12 protein genes, 2 rRNAs and 24 tRNAs of the mitochondrial genome (NC_007687.1) and the 293 loci on unplaced scaffolds that copy its protein genes, found by their best BLAST hit or by NCBI's name for them (`mitochondrial_loci()`; 331 rows in the count matrix of record, written to `05_differential-expression/03_analyses/count_matrix/mitochondrial_loci.csv`); `is_mt_encoded()` and `mt_protein_symbol()` |
| `pipeline_checks.R` | `02_thread-strength` (04, 05), `03_blast` (01, 04), `06_iso-seq-transcriptome` (02 to 04), `04_sequence-alignment` (03 to 08), `05_differential-expression` (05), `07_enrichment` (`_paths.R`, 01), `08_gene-annotation` (`_paths.R`, 02, 03), `09_gene-mechanics-correlation` (01, 02, 05) | `warn_unless()` checks counted into `RUN_provenance*.txt`, `provenance_lines()` (settings, git state, R and package versions, input MD5s), `psmfc_repo_root()`, and `check_go_release()`, which stops `07` and `08` unless `GO.db` holds GO release 2026-01-23 (`GO_RELEASE_OF_RECORD`) |
| `cloud_setup.sh` | not sourced; the setup script of the Claude Code cloud environment (paste it into the environment's settings, Setup script), or run once with root on any Ubuntu 24.04 machine | installs R 4.6.1 from CRAN's Ubuntu repository with R's recommended packages built for R 4.6, the system libraries the R packages compile against, pandoc, and BLAST+ 2.15.0 (MD5-checked); then restores the R packages of `../renv.lock` into `/opt/R/site-library-4.6`, which it makes R's site library, and checks every package against the lockfile. Safe to run again. The restore builds about 280 packages from source, about an hour on 4 cores (`RESTORE_R_PACKAGES=0` skips it and prints the command) |

Scripts reach this folder through their folder's `here::here()` root, `file.path(here::here(), "..", "tools", ...)`,
or through a `repo_root` they resolve first.

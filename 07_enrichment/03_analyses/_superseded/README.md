# _superseded

Inputs and results of the DAVID / REVIGO workflow (`../../01_code/_superseded/`), and the GO
results of the retired LC contrasts, kept as a record. Nothing reads them.

| Folder / file | Contents |
|---|---|
| `DAVID_lists/` | UniProt accession lists submitted to DAVID (moved from `06_differential-expression/03_analyses/DEG_lists/`) |
| `REVIGO_lists/` | GO-ID lists submitted to REVIGO (moved from the same place) |
| `Func_annot_DAVID/` | what DAVID returned: functional annotation charts and BP tables per TC contrast |
| `Revigo_results/` | what REVIGO returned, with copies of the submitted lists |
| `uniprot_BG_DAVID.txt` | an earlier DAVID background list, not de-duplicated (6,365 lines, 5,547 unique IDs) |
| `LC_enrichment/` | the LC contrasts' dot plots and result-table rows from the topGO / goseq / clusterProfiler / rrvgo run, retired with the LC contrasts (README inside) |

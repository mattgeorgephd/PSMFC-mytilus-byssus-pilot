# 02_data/_superseded

Gene-family count matrices written by the legacy `../../01_code/_superseded/11-byssal_thread_by_sample.Rmd`:
`HIF_GCM.csv` (hypoxia-inducible factor), `HSP_GCM.csv` (heat-shock proteins), `perox_GCM.csv`
(peroxidases) and `foot_byss_GCM.csv` (foot and byssus proteins). No current script reads them;
scripts 01 and 04 select candidate genes from the genome-wide annotation instead. Moved here
from `02_data/` because they are outputs, not inputs.

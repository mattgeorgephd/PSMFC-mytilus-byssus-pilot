# 03_analyses

Generated outputs, one numbered folder per script. Everything here is regenerable by scripts
01 to 05 from the inputs in `../02_data/` and the mussel workbook in
`../../01_mussel-measurements/`; the one hand-maintained input is
`../02_data/pad_area_measurements.xlsx`. The runner's reports and logs go to `knit_html/`
(git-ignored).

| Item | Produced by | Contents |
|---|---|---|
| `01_build-mussel-key/mussel-treatment-key.csv` | `01_build_mussel_key.Rmd` | One row per mussel tag: `species`, `mussel_trt` (the arm), `group`, `days_in_trt`, `rna_sequenced`. Built from `../../01_mussel-measurements/mussel-size-measurements.xlsx`, sheet `data`; read by script 02 |
| `02_extract-tensometer-data/thread-summary-raw-output.xlsx` | `02_extract_tensometer_data.Rmd` | Every extracted trace. Sheets: `data`, `coverage`, `pairing`. |
| `02_extract-tensometer-data/QC_plots/<source_folder>/` | `02_extract_tensometer_data.Rmd` | Per-trace loess QC plots, named after the source file; written on every run and git-ignored (only the folders' READMEs and five older plots no script writes are committed) |
| `03_assemble-thread-summary/thread-summary.xlsx` | `03_assemble_thread_summary.Rmd` | One row per trace with `pad_area`, `failure` and `adhesion_kpa` (sheet `data`). Read by scripts 04 and 05 and by `09_gene-mechanics-correlation` scripts 01, 03 and 04. Overwritten on every run of script 03. |

| `05_decompose-adhesion/` | `05_decompose_adhesion.Rmd` | Per-animal ANCOVA on mean peak force, maximum peak force and plaque area separately (`STATS_ancova_*.csv`); each-arm-vs-control figure; per-animal response classification (`mussel_response_classification.csv`, read by `09_gene-mechanics-correlation` script 01); failure-mode composition |

## Notes

Script 04 has one configuration decision, `INCLUDE_LAB_REFERENCE`, set at the top of the
script. It governs whether the day-0 lab-reference animals count as part of the baseline
reference pool drawn in the line+box panels; it does not affect the ANCOVA. It is FALSE,
warns if set TRUE, and
`RUN_provenance.txt` records which setting produced the files in `04_analyze-thread-strength/`,
so a folder is never ambiguous.

The two controls: **treatment control** (`mussel_trt == "control"`, T126-T137, day 3 in the
system under ambient conditions) is the reference for a stressor effect (the ANCOVA
reference arm, the DESeq2 TC contrasts). **Lab control** (`phase == "lab"`, T001-T012,
day 0, never in the system) is a descriptive comparison group for handling and time in the
system (`DESC_lab_reference.csv`); it is never a baseline and enters no model.

Every file in `04_analyze-thread-strength/` and `05_decompose-adhesion/` is regenerated by a fresh
run of scripts 04 and 05.
